# وب‌سایت آتیوار | ATIVAR

وب‌سایت سازمانی حرفه‌ای برای برند **آتیوار**، مجموعه تخصصی مشاوره فین‌تک، هوش مصنوعی سازمانی، معماری راهکارهای مالی دیجیتال و اجرای پروژه‌های فناوری.

## ویژگی‌های کلیدی

- **زبان و جهت**: فارسی (RTL)
- **تم**: Light Theme (سفید محور)
- **فناوری**: Next.js 15 (App Router), TypeScript, Tailwind CSS
- **سئو فنی**: Metadata، OpenGraph، robots.txt، sitemap.xml
- **فرم تماس**: اعتبارسنجی، API Route آماده توسعه
- **صفحات کلیدی**: صفحه اصلی، خدمات مشاوره، هوش مصنوعی سازمانی، ATIVAR AI Workspace، فین‌تک، طراحی و اجرای پروژه، DNA آتیوار، پروژه‌ها، دانش و تحلیل، تماس
- **صفحات حقوقی**: حریم خصوصی، شرایط استفاده، سلب مسئولیت

## راه‌اندازی پروژه

### پیش‌نیازها
- Node.js 18.18+ یا 20+
- npm / pnpm / yarn

### نصب وابستگی‌ها
```bash
npm install
```

### اجرای محیط توسعه
```bash
npm run dev
```

سایت روی [http://localhost:3000](http://localhost:3000) در دسترس خواهد بود.

### بیلد و اجرا در محیط تولید
```bash
npm run build
npm run start
```

### بررسی تایپ اسکریپت
```bash
npm run typecheck
```

## ساختار پروژه

```
src/
├── app/          # App Router صفحات و API
├── components/   # کامپوننت‌های layout, ui, forms
├── lib/          # ابزارها و توابع کمکی
└── styles/       # استایل‌های اضافی
```

## نکات مهم

- **محتوای واقعی**: هیچ اطلاعات ساختگی (اعضای تیم، پروژه‌ها، مجوزها) درج نشده است. در صورت نبود اطلاعات، بخش مربوط با توضیح مناسب یا Placeholder مشخص شده است.
- **تفکیک خدمات**: خدمات مشاوره و فناوری از فعالیت‌های نیازمند مجوز به‌خوبی تفکیک شده‌اند.
- **رویکرد مسئله‌محور**: طراحی سایت بر اساس نیازهای مدیران ارشد و تبدیل به سرنخ فروش تمرکز دارد.
- **امنیت**: کلیدهای API نباید در سمت کلاینت قرار بگیرند. فرم‌ها دارای اعتبارسنجی سرور هستند.

## اطلاعات مورد نیاز برای تکمیل نهایی

- لوگوی رسمی ATIVAR (SVG)
- تصاویر واقعی اعضای تیم (در صورت موجود و مجاز)
- رزومه/سوابق تأییدشده اعضا
- مستندات مطالعه موردی پروژه فلزات گران‌بها
- اطلاعات تماس رسمی (آدرس، ایمیل، شماره تماس)
- مجوزها یا گواهینامه‌های قابل انتشار
