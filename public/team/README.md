# تصاویر اعضای تیم

فایل تصویر هر عضو با نام مشخص‌شده در `team/team-data.ts` داخل همین پوشه قرار می‌گیرد.
مسیر تصویر در داده‌ها به شکل `/team/<file-name>` ثبت شده است.

| عضو | نام فایل |
| --- | --- |
| امیرعلی ریاضی | `amirali-riazi.webp` |
| امید قنبری | `omid-ghanbari.webp` |
| محمدمهدی پازوکی | `mohammadmehdi-pazouki.webp` |
| حمید علیزاده | `hamid-alizadeh.webp` |

نکات:

- تصاویر فعلی آپلود شده‌اند؛ نسبت پیشنهادی برای تصاویر جایگزین ۴:۵ و حداقل عرض ۸۰۰ پیکسل است.
- تا زمانی که تصویری آپلود نشود یا بارگذاری آن ناموفق باشد، کارت همان عضو مونوگرام (حروف اول نام) نمایش می‌دهد.
- اگر فرمت یا نام فایل را تغییر دادید، مقدار `image` را در `team/team-data.ts` به‌روزرسانی کنید.
- در نسخه production، پوشه `public/team` همراه با فایل‌ها باید روی سرور موجود باشد؛ در صورت تغییر داده‌ها یا مسیرها، یک build جدید لازم است.
